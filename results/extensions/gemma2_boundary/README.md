# Gemma2 Boundary Evidence

This directory is the final-paper source for the Gemma2 incomplete key-only
recovery statement. `case_level.csv` is a response-free reduction of the
completed formal run. `summary.csv` is derived from those rows and separates
exact-at-budget counts from cumulative unique recovery.

The older Gemma2 bundle under `results/supporting/gemma2_9b/` is a superseded
exploratory run and is not used for the final PRICAI claim.
